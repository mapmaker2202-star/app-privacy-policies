스포츠도감 개인정보처리방침

시행일: 2026년 10월 5일 · Android 1.0 / iOS 1.0

직접 수집하는 개인정보

스포츠도감은 회원가입을 요구하지 않으며 이름, 이메일, 사진, 연락처, 정확한 위치를 입력받거나 자체 서버로 수집하지 않습니다. iOS 1.0에는 광고와 분석 SDK가 포함되지 않습니다.

Android 광고와 Google AdMob

Android 버전은 Google Mobile Ads SDK를 통해 하단 배너 광고를 제공합니다. 광고 SDK는 광고 제공, 분석, 보안 및 부정 사용 방지를 위해 IP 주소(대략적인 위치 추정에 사용될 수 있음), 앱 실행과 광고 상호작용, 오류·성능 진단 정보, 기기 및 앱 관련 식별자를 처리하고 Google에 전송할 수 있습니다. SDK의 전송은 TLS로 암호화됩니다. 앱은 아동 대상 처리·동의 연령 미만 처리·일반 등급 제한과 비개인 맞춤 광고 설정을 적용합니다. 광고 처리 방식은 iOS 무광고 버전과 다릅니다.

Google의 처리 및 보관에 관한 자세한 내용은 Google 개인정보처리방침과 Google Mobile Ads SDK 데이터 공개 안내를 확인하세요. 자체 계정 및 서버로 수집하는 개인정보는 없어 개발자 서버에서 삭제할 계정 정보는 없습니다. 기기의 학습 기록은 설정의 기록 초기화 또는 앱 데이터 삭제로 지울 수 있고, 광고 SDK 관련 정보와 권리는 Google 정책을 참고하세요.

기기에 저장되는 정보

메달 카드, 즐겨찾기, 최근 본 종목, 오답, 학습 기록, 퀴즈 점수, 언어와 설정은 사용 중인 기기에 저장됩니다. 앱 삭제나 기기 데이터 삭제로 기록이 사라질 수 있습니다. 기록은 설정에서 초기화할 수 있습니다.

백업과 공유

사용자의 선택에 따라 학습 기록을 암호화되지 않은 JSON 파일로 백업하거나 종목 소개 문구를 다른 앱에 공유할 수 있습니다. 백업 파일을 만들 때 앱의 임시 저장 공간을 사용하며, 저장 위치와 수신 앱은 사용자가 선택합니다. 외부 사본은 저장한 위치에서 직접 관리하고 삭제해야 합니다. 복원은 현재 기록을 백업의 기록으로 바꿉니다.

외부 링크

사진 출처와 라이선스 링크를 열면 해당 외부 사이트의 정책이 적용됩니다. 학습 기록을 개발자 서버로 자동 전송하거나 계정과 동기화하지 않습니다.

스포츠도감 지원

사진과 쉬운 설명으로 134종목을 만나고 퀴즈·비교·복습을 통해 스포츠 상식을 익혀보세요.

개인정보와 앱 이용 문의: support@wsappstudio.com

문의 시 기기 모델, 운영체제 버전, 앱 버전과 오류가 난 화면·동작을 알려주세요. 비밀번호나 민감한 개인정보를 보내지 않아도 됩니다. 잘못된 사진이나 정보는 종목 이름과 함께 알려주세요.

변경 안내

앱의 개인정보 처리 방식이 바뀌면 시행일과 내용을 이 페이지에 갱신합니다.
